Email Configuration (Resend)

Overdue reminder emails are sent via Resend — free, no IT setup, no passwords needed.

One-time setup (~2 minutes):

  1. Sign up free at resend.com
  2. Go to API Keys → Create API Key → copy the key
  3. Go to Emails → Verify a sender address → enter and verify your email

Then add these in Supabase Dashboard → Edge Functions → Secrets:

RESEND_API_KEY = re_xxxxxxxxxxxx

FROM_EMAIL = your verified email address

Then deploy the Edge Function from the supabase/functions/send-overdue-emails/ folder.
